# Задача в общих чертах
По входной PNG‑картинке интерфейсного компонента создай первичную реализацию набора файлов React‑компонента.

Требования:
- результат должен быть максимально близок к картинке по структуре и смыслам;
- код должен быть простым и понятным;
- не используй внешние зависимости, кроме React (и базовых возможностей TS/JS);
- Tailwind CSS допустим;
- используй TypeScript;
- компонент должен быть “безопасным”: не падать на неожиданных значениях пропсов.

Важно: верни результат строго в формате JSON, который запросит система ниже.
