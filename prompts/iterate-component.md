# Задача в общих чертах
По текущим файлам и уточняющему промпту пользователя обнови существующий набор файлов React‑компонента.

Требования:
- меняй только те файлы, которые действительно нужно обновить;
- сохраняй совместимость между `Component.tsx`, `props.ts`, `mock.ts`, `styles.ts` и `Component.stories.ts`;
- не используй внешние зависимости, кроме React и базовых возможностей TS/JS;
- Tailwind CSS допустим;
- код должен оставаться простым, понятным и устойчивым к неожиданным значениям пропсов.

Важно: верни результат строго в формате JSON, который запросит система ниже.
