# Platform notes

## Общий принцип

На `macOS`, `Windows` и `Linux` пользовательский сценарий одинаков по смыслу:

- администратор поднимает локальное приложение;
- пользователь открывает его в браузере;
- до допуска видит страницу состояния;
- после allowlist-проверки получает доступ к задачам и лаборатории.

Пользовательский quick start не должен требовать bash-специфичных шагов. Все технические операции относятся к админскому контуру.

## macOS

- Рекомендуемый стек: `Node.js 20`, `22` или `24`, актуальный `npm`.
- Запуск и smoke-check выполняются из корня репозитория.
- Пользователь работает только в браузере.

## Windows

- Рекомендуемый стек: `Node.js 20`, `22` или `24`, актуальный `npm`.
- Не предполагается, что пользователь или администратор обязаны использовать PowerShell-специфичную логику для обычного браузерного сценария.
- Пользователь работает только в браузере.

## Linux

- Рекомендуемый стек: `Node.js 20`, `22` или `24`, актуальный `npm`.
- Quick start не должен зависеть от bash-специфичных пользовательских действий.
- Пользователь работает только в браузере.
