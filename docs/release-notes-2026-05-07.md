# Release Notes — 2026-05-07

## Роль документа

Это исторические release notes. Они помогают понять, что менялось в продукте, но не заменяют [README.md](README.md), [INSTALL.md](INSTALL.md) и профильные инструкции из `docs/**`.

## Новое

- В системе появились более понятные страницы: отдельные страницы для задач, уровней, входа, настроек и помощи.
- Теперь задачу можно полностью сбросить и начать заново.
- В настройках появилась отдельная возможность обновить учебные материалы.

## Что стало удобнее

- При уточнении запроса больше не нужно выбирать файлы вручную: система сама подставляет всё нужное.
- Поле для уточняющего запроса стало похоже на чат: оно растёт по мере ввода, всегда остаётся внизу экрана, запрос можно отправить клавишей `Enter`, а новую строку добавить через `Shift+Enter`.
- Система строже следит за тем, какие файлы доступны на текущем шаге задачи, чтобы не показывать и не использовать лишнее.
- Ваш прогресс и результаты работы теперь лучше защищены при обновлении системы.
- Доступ в систему через allowlist теперь нужно подтверждать заново раз в сутки.

## Установка и обновление

- Установка стала понятнее: у системы теперь один основной рабочий контур, без разделения на “основную часть” и отдельную `lab`.
- Настройки запуска стали проще для редактирования: вместо скрытого env-файла используется обычный `desengine.config.txt`.
- Учебные материалы теперь обновляются отдельно и более явно.
- При обновлении системы ваши личные результаты и прогресс не должны теряться.
