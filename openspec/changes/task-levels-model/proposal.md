## Why

Нужно ввести общую систему уровней обучения, которая определяет дидактику, внешний вид лаборатории и правила прогресса пользователя. Без этой модели дальше нельзя аккуратно строить образовательный сценарий: уровни будут путаться с задачами, а доступ к контенту и логика продвижения окажутся размазаны по коду.

## What Changes

- Добавляем общую модель уровней, единых для всех задач.
- Фиксируем, что каждая задача имеет собственный диапазон уровней от `1` до `N`, где `N` зависит от задачи.
- Фиксируем, что пользователь проходит одну и ту же задачу последовательно по уровням `1 -> 2 -> ... -> N`.
- Добавляем модель прогресса по уровням задачи: доступ, работа, завершение, блокировка.
- Фиксируем правила завершения уровня задачи: либо явное завершение пользователем, либо исчерпание лимита промптов для этого уровня.
- Добавляем настройку `N промптов на задачу` для каждого уровня.
- Добавляем общий контент уровня, доступный по всем задачам этого уровня.
- Фиксируем, что внешний вид лаборатории определяется уровнем и может полностью отличаться между уровнями.
- Фиксируем, что новые задачи по мере роста уровня не появляются: пользователь всё время работает с одним и тем же набором задач, но на новом уровне сложности.
- Фиксируем, что не каждая задача обязана иметь все уровни, и пользователь может остановиться на любом уровне.

## Capabilities

### New Capabilities
- `task-levels`: модель уровней задач, прогресса, лимитов промптов и доступа к контенту уровня.

### Modified Capabilities
- `task`: каждая задача имеет собственный диапазон уровней и на каждом уровне остаётся той же самой задачей.
- `iteration`: количество промптов по задаче ограничивается настройкой уровня.
- `user-progress`: прогресс пользователя должен учитывать статус прохождения задачи на её уровне.

## Impact

- Данные: потребуется хранить каталог уровней, максимальный уровень задачи, текущий уровень задачи у пользователя и лимиты промптов.
- UI/UX: лаборатория станет level-specific, а не общей для всех задач.
- Прогресс: потребуется явная модель статусов уровня задачи и правила открытия следующего шага.
- Контент: потребуется отдельное хранилище материалов уровня, не привязанное к конкретной задаче.
