## ADDED Requirements

### Requirement: Прогресс хранит статус задачи на уровне

Система SHALL хранить статус прохождения задачи пользователем с учётом её уровня.

#### Scenario: Пользователь начал задачу
- **WHEN** пользователь приступил к задаче
- **THEN** система сохраняет статус задачи на её уровне как минимум в состоянии `in_progress`

#### Scenario: Пользователь завершил задачу
- **WHEN** задача завершена вручную или по лимиту промптов
- **THEN** система сохраняет статус задачи на её уровне как `completed`

### Requirement: Прогресс хранит текущий уровень пользователя внутри задачи

Система SHALL хранить для каждой задачи текущий уровень, на котором находится пользователь.

#### Scenario: Пользователь перешёл на следующий уровень задачи
- **WHEN** пользователь завершил задачу на уровне `L`, и для задачи существует уровень `L+1`
- **THEN** система сохраняет, что текущим уровнем этой задачи становится `L+1`
