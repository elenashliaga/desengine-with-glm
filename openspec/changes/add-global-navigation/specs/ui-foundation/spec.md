## ADDED Requirements

### Requirement: Глобальная навигационная полоса является каноническим shell-паттерном

Система SHALL использовать `Navigation` как канонический верхний shell-компонент product-shell интерфейса.

#### Scenario: Команда добавляет или меняет product-shell страницу
- **WHEN** страница относится к product-shell интерфейсу
- **THEN** она использует общий `Navigation`, а не локально собранный верхний набор ссылок

### Requirement: Navigation имеет компактный контрастный визуальный контракт

Система SHALL рендерить `Navigation` во всю ширину, с минимально возможной высотой, чёрным фоном и белыми подчёркнутыми ссылками.

#### Scenario: Пользователь видит верхнюю навигационную полосу
- **WHEN** product-shell страница отрисована
- **THEN** `Navigation` занимает всю доступную ширину
- **AND** имеет чёрный фон
- **AND** показывает ссылки белым цветом с подчёркиванием
- **AND** не раздувается по высоте больше необходимого минимума
