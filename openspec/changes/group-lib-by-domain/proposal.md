## Why

Каталог `lib/` разросся плоским списком файлов с разными доменами (`access`, `task`, `llm`, `onboarding`, инфраструктура), из-за чего сложнее ориентироваться в зависимостях и точках ответственности.

## What Changes

- Сгруппировать файлы `lib/` по доменным подпапкам.
- Обновить импорты по всему проекту на новые пути.
- Не использовать временные алиасы/прокси-реэкспорты старых путей.

## Impact

- Изменятся внутренние import-пути в `app`, `components`, `lib`, `test`, `tools`.
- Поведение системы не меняется; рефактор только структурный.
