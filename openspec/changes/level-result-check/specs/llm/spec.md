## MODIFIED Requirements

### Requirement: Общий базовый промпт участвует во всех LLM-запросах

Система SHALL рассматривать checking run уровня как ещё один официальный LLM-запрос лаборатории.

#### Scenario: Система выполняет проверку уровня
- **WHEN** система формирует checking run
- **THEN** она включает общий базовый prompt-контур, используемый лабораторией

### Requirement: Уровень имеет отдельный hidden checking prompt

Система SHALL использовать для проверки уровня отдельный hidden checking prompt уровня.

#### Scenario: Система выполняет checking run для уровня
- **WHEN** runtime подбирает hidden prompt проверки уровня
- **THEN** он читает `onboarding/prompts/levels/<levelId>/check.md`

### Requirement: Ошибки LLM-провайдера объясняются пользователю

Система SHALL различать содержательный fail проверки и технический сбой checking run.

#### Scenario: Checking run дал содержательный fail
- **WHEN** система получила валидный structured-ответ проверки с `passed = false`
- **THEN** она трактует это как результативную проверку уровня
- **AND** показывает пользовательское сообщение из результата проверки

#### Scenario: Checking run завершился техническим сбоем
- **WHEN** система не смогла получить валидный structured-ответ проверки
- **THEN** она не трактует это как содержательную проверку
- **AND** показывает пользователю понятное сообщение о техническом сбое
