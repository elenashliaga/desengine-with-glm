## ADDED Requirements

### Requirement: Система поддерживает адаптер Mistral

Система SHALL поддерживать отдельный адаптер для Mistral.

#### Scenario: Оператор выбирает Mistral
- **WHEN** конфигурация приложения переключена на Mistral
- **THEN** система использует адаптер Mistral для LLM-вызовов

### Requirement: Конфигурация Mistral задаётся явно

Система SHALL брать параметры подключения к Mistral из локальной конфигурации приложения.

#### Scenario: Оператор настраивает Mistral
- **WHEN** оператор задаёт обязательные параметры подключения к Mistral
- **THEN** система использует их без изменения кода

### Requirement: Ошибки Mistral различаются по типам

Система SHALL различать как минимум следующие классы ошибок для Mistral:
- неполная конфигурация;
- ошибка авторизации;
- недоступность endpoint;
- таймаут;
- невалидный ответ провайдера.

#### Scenario: Авторизация Mistral не прошла
- **WHEN** провайдер возвращает ошибку авторизации
- **THEN** пользователь видит понятное сообщение об ошибке доступа к Mistral
