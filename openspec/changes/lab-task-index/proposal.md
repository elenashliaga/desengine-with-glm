## Why

Пользователю нужен обзор всех задач и их состояния без открытия каждой задачи по отдельности.

## What Changes

- Добавляем индекс-страницу со списком задач.
- Для каждой задачи показываем статус завершения и остаток уточняющих запросов.
- Из списка задач можно перейти на страницу конкретной задачи.

## Impact

- Потребуется агрегировать локальный прогресс по всем задачам.
- Потребуется добавить отдельный маршрут списка задач.
