## ADDED Requirements

### Requirement: Прогресс задачи хранит остаток уточнений

Система SHALL хранить для каждой задачи число использованных и оставшихся уточняющих запросов.

#### Scenario: Пользователь смотрит на прогресс задачи
- **WHEN** у задачи есть история уточняющих запросов
- **THEN** система может вычислить, сколько уточняющих запросов уже использовано и сколько осталось до лимита 10

### Requirement: Индекс-страница показывает статусы задач

Система SHALL иметь индекс-страницу со списком задач и их статусами.

#### Scenario: Пользователь открывает индекс-страницу
- **WHEN** пользователь открывает список задач
- **THEN** система показывает для каждой задачи, завершена ли она и сколько уточняющих запросов осталось
- **AND** каждая задача доступна как ссылка на страницу этой задачи
