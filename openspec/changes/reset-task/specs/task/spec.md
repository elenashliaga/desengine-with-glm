## MODIFIED Requirements

### Requirement: Задание включает текущее состояние файлов

Система SHALL хранить текущее состояние набора файлов компонента как часть задания и SHALL поддерживать явный reset задачи в исходное состояние.

При reset система SHALL удалить все рабочие и сгенерённые файлы задачи, кроме стартовых файлов задачи.

#### Scenario: Пользователь возвращается к заданию позже
- **WHEN** пользователь открывает ранее начатое задание
- **THEN** система показывает текущее состояние файлов из задания

#### Scenario: Пользователь сбрасывает задачу
- **WHEN** пользователь запускает reset задачи
- **THEN** система удаляет все рабочие и сгенерённые файлы
- **AND** сохраняет только стартовые файлы задачи

### Requirement: PNG обязателен для задания на MVP

Система SHALL требовать level-specific PNG-вводные как обязательную часть задания на соответствующем уровне.

Стартовые файлы задачи SHALL считаться исходным набором, который сохраняется при reset.

#### Scenario: Пользователь сбрасывает задачу
- **WHEN** reset задачи завершён
- **THEN** стартовые файлы `base`, `variants` и `config` остаются на месте
