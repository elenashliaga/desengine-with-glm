## MODIFIED Requirements

### Requirement: Система хранит прогресс пользователя по уровням задач

Система SHALL хранить прогресс пользователя по задачам и уровням, и SHALL уметь возвращать задачу в состояние `Не начиналась` после reset.

#### Scenario: Пользователь решает задачу
- **WHEN** пользователь проходит задачу на некотором уровне
- **THEN** система обновляет его прогресс по этой задаче

#### Scenario: Пользователь сбрасывает задачу
- **WHEN** reset задачи завершён
- **THEN** система считает эту задачу не начатой
- **AND** следующий вход в задачу проходит обычный стартовый сценарий
