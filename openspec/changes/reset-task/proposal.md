## Why

Пользователю нужен простой способ начать работу над задачей заново, не очищая её вручную по файлам и не оставляя старую историю уточняющих запросов. Для этого системе нужна явная операция сброса задачи в исходное состояние.

## What Changes

- Добавляем действие `Сбросить задачу`.
- Фиксируем, что при сбросе удаляются все сгенерённые и рабочие файлы задачи, кроме стартовых файлов.
- Фиксируем, что после сброса стирается история уточняющих запросов по задаче.
- Фиксируем, что после сброса задача возвращается в состояние `Не начиналась`.

## Capabilities

### New Capabilities
- *(пусто)*

### Modified Capabilities
- `task`: задача поддерживает возврат в исходное состояние через явный reset.
- `iteration`: история уточняющих запросов задачи очищается при reset.
- `user-progress`: прогресс по задаче должен отражать, что задача снова не начиналась.

## Impact

- UI/UX: потребуется отдельная кнопка `Сбросить задачу` и понятное подтверждение/состояние после сброса.
- Файловая система: потребуется безопасно удалить рабочие файлы задачи, не трогая стартовые артефакты.
- Состояние: потребуется синхронно очистить историю уточнений и вернуть задачу в стартовое состояние.
