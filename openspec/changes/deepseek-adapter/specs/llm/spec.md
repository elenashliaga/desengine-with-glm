## MODIFIED Requirements

### Requirement: На MVP используется настраиваемый LLM-провайдер

Система SHALL использовать тот LLM-провайдер, который выбран конфигурацией приложения.

Поддерживаются как минимум следующие режимы:
- OpenAI по ключу;
- Ollama по URL;
- DeepSeek.

#### Scenario: Конфигурация выбрала DeepSeek
- **WHEN** приложение настроено на режим DeepSeek
- **THEN** система отправляет LLM-запросы через адаптер DeepSeek

### Requirement: Ошибки LLM-провайдера объясняются пользователю

Система SHALL показывать пользователю понятные сообщения в случаях:
- отсутствует обязательная конфигурация провайдера;
- ошибка авторизации;
- сетевые ошибки;
- таймауты;
- лимиты или ошибки провайдера;
- невалидный ответ.

#### Scenario: DeepSeek вернул ошибку
- **WHEN** адаптер DeepSeek получает ошибку от провайдера
- **THEN** пользователь видит понятное сообщение и может повторить действие после исправления причины
