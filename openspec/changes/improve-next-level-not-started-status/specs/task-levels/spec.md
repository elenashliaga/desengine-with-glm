## MODIFIED Requirements

### Requirement: Следующий уровень открывается сразу как текущий, но не начатый

Система SHALL после успешного завершения уровня переводить задачу на следующий уровень той же задачи без обязательного отдельного transition-screen.

#### Scenario: У задачи есть следующий уровень
- **WHEN** пользователь завершил задачу на уровне `L`
- **THEN** система делает уровень `L+1` текущим
- **AND** открывает задачу на этом уровне
- **AND** показывает стартовую страницу уровня `L+1`, пока пользователь явно не начнёт его

#### Scenario: Пользователь возвращается к списку задач до старта нового уровня
- **WHEN** уровень `L+1` уже стал текущим
- **AND** пользователь ещё не запускал его start-flow
- **THEN** стартовая страница задач показывает задачу как уже начатую
- **AND** одновременно показывает, что уровень `L+1` ещё не начат
