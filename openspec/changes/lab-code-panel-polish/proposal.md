## Why

Кодовая панель лаборатории уже работает, но в ежедневном использовании раздражает несколькими деталями:
- чёрный фон нравится не всем;
- часть подсвеченных “ошибок” не является полезной ошибкой для этого контекста;
- не хватает явного `Скопировать` и простой внешней подсказки, что код можно показать ChatGPT в обычном чате;
- переключатели файлов выглядят сыро;
- переключение между файлами ощущается как тяжёлая навигация и дёргает страницу наверх.

Нужен отдельный polish-change про кодовую панель как пользовательский инструмент.

## What Changes

- Пересматриваем фон кодовой панели: убираем жёсткий чёрный фон или делаем его настройкой.
- Ослабляем или отключаем нерелевантную подсветку “ошибок”.
- Добавляем кнопку `Скопировать`.
- Добавляем короткую пользовательскую подсказку про обычный чат ChatGPT.
- Подтягиваем визуальный стиль переключателей файлов.
- Делаем переключение между файлами локальным, без прыжка наверх и без полной перезагрузки страницы.

## Capabilities

### Modified Capabilities
- `task`: рабочий кодовый блок задачи становится спокойнее, удобнее и меньше похож на route-transition.
- `ui-foundation`: shell-компоненты переключения файлов и действий над кодом получают более аккуратный стандарт.

## Impact

- UI/UX: потребуется доработать code panel и file-switcher.
- Navigation: потребуется отвязать переключение файлов от тяжёлой page navigation.
- Editor diagnostics: потребуется пересмотреть, какие ошибки реально нужно показывать пользователю в лаборатории.
