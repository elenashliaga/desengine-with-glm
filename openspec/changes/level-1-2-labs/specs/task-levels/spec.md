## MODIFIED Requirements

### Requirement: Каждый уровень начинается со скрытого инициирующего запуска

Система SHALL выполнять для каждого уровня задачи отдельный скрытый инициирующий запуск до первых уточняющих промптов пользователя.

Инициирующий запуск SHALL зависеть от уровня задачи и использовать:
- level-specific инициирующий промпт;
- визуальные вводные и размеры, определённые глобальным level-config текущего уровня.

#### Scenario: Пользователь впервые входит в новый уровень задачи
- **WHEN** пользователь открывает задачу на уровне `L`, который ещё не был инициализирован
- **THEN** система выполняет скрытый инициирующий запуск этого уровня
- **AND** использует prompt и картинки именно этого уровня
- **AND** только после него разрешает обычные уточняющие промпты

### Requirement: Описание уровня берётся из файлов уровня

Система SHALL получать пользовательское описание уровня из `overview.md` в папке уровня, а не из `config.json`.

#### Scenario: Пользователь открывает экран уровня
- **WHEN** система показывает описание уровня
- **THEN** она использует содержимое `levels/<levelId>/overview.md`
