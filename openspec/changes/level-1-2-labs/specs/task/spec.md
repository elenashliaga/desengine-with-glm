## MODIFIED Requirements

### Requirement: PNG обязателен для задания на MVP

Система SHALL требовать level-specific PNG-вводные как обязательную часть задания на соответствующем уровне, но сами правила набора этих вводных SHALL задаваться глобальным контрактом уровня, а не отдельным каталогом внутри каждой задачи.

Для уровня 1 глобальный контракт уровня SHALL требовать:
- `base.png`;
- размеры `base`.

Для уровня 2 глобальный контракт уровня SHALL требовать:
- `base.png`;
- `variants.png`;
- размеры `base` и `variants`.

Для самой задачи SHALL быть обязательным как минимум:
- размеры картинок по именованным типам, которые реально используются уровнями этой задачи;
- task-specific пояснение соответствующего уровня.

#### Scenario: Пользователь пытается открыть уровень 1 без base-картинки
- **WHEN** для уровня 1 отсутствует обязательная `base.png` или размеры `base`
- **THEN** система не может выполнить инициирующий запуск уровня 1 и сообщает об ошибке

#### Scenario: Пользователь пытается открыть уровень 2 без variants-картинки
- **WHEN** для уровня 2 отсутствует обязательная `variants.png` или размеры `variants`
- **THEN** система не может выполнить инициирующий запуск уровня 2 и сообщает об ошибке

#### Scenario: Пользователь открывает задачу без task-specific пояснения уровня
- **WHEN** для текущей задачи отсутствует уникальное пояснение этого уровня
- **THEN** система не может считать задачу полностью оформленной для этого уровня
