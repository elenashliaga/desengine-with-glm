## ADDED Requirements

### Requirement: Стартовый экран уровня 1 показывает допустимые для уровня картинки

Система SHALL на стартовом экране уровня 1 конкретной задачи показывать все картинки уровня 1, которые помечены как показываемые в глобальном level-config этого уровня.

#### Scenario: Пользователь открывает стартовый экран уровня 1 задачи
- **WHEN** пользователь открывает стартовый экран уровня 1 конкретной задачи
- **THEN** система показывает все картинки из `images[]` глобального level-config уровня 1, у которых `show=true`
- **AND** не показывает картинки, у которых `show=false`
- **AND** не показывает технические имена файлов рядом с preview

### Requirement: Стартовый экран уровня L>1 показывает допустимые картинки текущего уровня и рендер предыдущего уровня

Система SHALL на стартовом экране уровня `L>1` конкретной задачи показывать:

- картинки текущего уровня `L`, допустимые к показу по глобальному level-config;
- рендер результата предыдущего уровня `L-1` как визуальный контекст.

#### Scenario: Пользователь открывает стартовый экран уровня 2+ задачи
- **WHEN** пользователь открывает стартовый экран уровня `L>1` конкретной задачи
- **THEN** система показывает все картинки из `images[]` глобального level-config уровня `L`, у которых `show=true`
- **AND** показывает блок рендера результата уровня `L-1`

#### Scenario: Результат предыдущего уровня недоступен
- **WHEN** пользователь открывает стартовый экран уровня `L>1` конкретной задачи
- **AND** результат уровня `L-1` недоступен
- **THEN** система показывает понятный fallback для блока предыдущего уровня
- **AND** стартовый экран остаётся рабочим (не падает и не блокирует пользователя)
