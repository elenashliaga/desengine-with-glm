## Why

Сейчас у задачи есть явный старт только “в целом”: для первой встречи с задачей пользователь видит стартовый экран задачи, а для следующих уровней попадает сразу в рабочий экран или в переходный сценарий. Из-за этого модель уровней остаётся непоследовательной:
- у первого уровня нет собственной отдельной страницы начала;
- у следующих уровней нет симметричного одноразового входа “начать именно этот уровень”;
- состояние задачи хранит “начата / не начата” в основном на уровне всей задачи, хотя по смыслу запуск происходит и переживается на каждом уровне отдельно.

Нужен единый контракт: каждый уровень, включая первый, имеет свою страницу начала работы, а у задачи на каждом уровне есть отдельное состояние “начат / не начат”.

## What Changes

- Фиксируем, что у каждого уровня задачи, включая первый, есть собственная одноразовая стартовая страница.
- Фиксируем, что пользователь начинает каждый уровень явным действием со стартовой страницы этого уровня.
- Фиксируем, что после явного старта уровня выполняется скрытый init-запуск уровня, а затем открывается рабочий экран.
- Фиксируем, что стартовая страница уровня показывается только один раз на уровень.
- Фиксируем, что задача хранит не только текущий уровень, но и состояние “начат / не начат” для текущего уровня.
- Фиксируем, что отдельный глобальный статус “задача вообще не начиналась” становится производным случаем: это просто ситуация, когда не начат первый уровень.

## Capabilities

### Modified Capabilities
- `task`: задача получает обязательный одноразовый старт на каждом уровне, включая первый.
- `task-levels`: переход между уровнями завершается состоянием “уровень открыт, но ещё не начат”.
- `user-progress`: прогресс должен различать общий прогресс по задаче и факт начала конкретного уровня.

## Impact

- UX: первый и все последующие уровни будут начинаться по одной и той же модели.
- Progress model: потребуется расширить/уточнить хранение статуса уровня.
- Runtime flow: init-запуск уровня будет привязан к явному старту этого уровня, а не только к общей задаче.
