## Context

Текущая цель — рабочий MVP на ChatGPT API. Пользователь работает локально, с заданиями (PNG + набор файлов) и итерациями, которые изменяют несколько файлов за один запуск.

Ключевые ограничения:
- PNG обязателен для итерации.
- Итерация должна учитывать историю промптов.
- Результат итерации — многофайловый набор.
- Публикуемый слепок не должен содержать секреты.

## Goals / Non-Goals

**Goals:**
- Подключить ChatGPT API как LLM‑провайдер на MVP.
- Обеспечить многофайловый результат за одну итерацию.
- Обеспечить понятные ошибки и минимальный учёт затрат.

**Non-Goals:**
- Поддержка локальных моделей/провайдеров.
- Обучающий режим и дидактические промпты (кроме совместимости структуры).
- Многопользовательность.
- Веб-развёртывание как основной сценарий продукта на MVP.

## Decisions

- Формат ответа модели для многофайлового результата должен быть однозначно парсимым и устойчивым к “лишнему тексту”.
  - Альтернативы: строгий JSON; “архив” в markdown; разделители по файлам.
  - Решение фиксируется в отдельном change после выбора конкретного формата.

- История промптов хранится локально в структуре задания и входит в контекст итерации целиком.
  - Альтернативы: суммаризация; ограничение окна.
  - На MVP — без суммаризации, пока не упрёмся в лимиты.

- Стратегия развёртывания для MVP — local-first.
  - Базовый сценарий: локальная лаборатория, где задачи, промпты, прогресс и ключ пользователя живут на машине пользователя.
  - Ближайшая упаковка: desktop-оболочка поверх локальной лаборатории.
  - Альтернативы: сайт как основная форма продукта; Electron; Tauri.
  - Принятое направление: сначала довести локальную лабораторию, затем завернуть её в desktop-оболочку; веб-сервис не является ближайшей целью.

## Risks / Trade-offs

- [Лимиты контекста] → На MVP возможно быстро упрёмся в размер PNG + история + файлы → потребуется стратегия усечения/суммаризации.
- [Секреты в контенте] → Пользователь может вставить секрет в промпт/файлы → нужны предупреждения при публикации слепка.
- [Веб-развёртывание отложено] → публикация на сайте сейчас замедлит запуск из-за backend, security и multi-user задач → сначала закрепляем local-first модель и desktop-упаковку.
