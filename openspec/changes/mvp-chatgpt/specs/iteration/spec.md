## ADDED Requirements

### Requirement: Итерация возвращает многофайловый результат за один запуск

Система SHALL поддерживать один запуск LLM, который возвращает обновления для нескольких файлов набора.

#### Scenario: Пользователь запускает итерацию по нескольким вводным файлам
- **WHEN** пользователь включает в контекст итерации несколько файлов
- **THEN** результат итерации может содержать обновления для любого из этих файлов

### Requirement: Старт задания создаёт первичный набор файлов по PNG

Система SHALL поддерживать “старт задания”: первый запуск LLM по PNG‑картинке, который создаёт первичный набор файлов компонента в каталоге задания.

#### Scenario: Пользователь нажимает “Да, начать”
- **WHEN** пользователь подтверждает старт задания
- **THEN** система вызывает LLM по PNG и сохраняет сгенерированные файлы в каталог задания

### Requirement: Рендер результата не зависит от бандлера

Система SHALL уметь показывать результат рендера компонента по текущим файлам задачи без необходимости пересборки dev-сервера.

#### Scenario: Пользователь редактирует Component.tsx и сохраняет
- **WHEN** пользователь сохраняет изменения в `Component.tsx`
- **THEN** результат рендера обновляется без перезапуска dev-сервера

#### Scenario: Пользователь открывает выбранное задание в /lab
- **WHEN** система загружает `Component.tsx`, `styles.ts` и `mock.ts` из каталога задания
- **THEN** система рендерит компонент справа от PNG без зависимости от CSS-импортов и без сборки отдельного preview-бандла
- **AND** система использует данные из `mock.ts` как входные props для предпросмотра

### Requirement: Уточняющий промпт запускает новую итерацию по выбранным файлам

Система SHALL позволять пользователю в `/lab` ввести уточняющий промпт, выбрать файлы контекста и запустить новую итерацию LLM по текущему состоянию задания.

#### Scenario: Пользователь запускает уточнение без выбора файлов
- **WHEN** пользователь не меняет список файлов контекста перед запуском уточнения
- **THEN** система включает в итерацию все редактируемые файлы задания

#### Scenario: Пользователь запускает уточнение по выбранным файлам
- **WHEN** пользователь вводит уточняющий промпт и выбирает подмножество файлов контекста
- **THEN** система отправляет в контекст итерации текущий промпт, историю промптов и только выбранные файлы
- **AND** после успешного ответа сохраняет обновлённые файлы и дописывает промпт в историю задания
