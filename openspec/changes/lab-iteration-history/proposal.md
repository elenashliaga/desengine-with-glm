## Why

История уточняющих запросов в рабочем экране задачи должна стать более управляемой и информативной: пользователю нужно видеть порядок запросов, их лимит, условную стоимость и фактические изменения.

## What Changes

- Нумеруем уточняющие запросы в рамках задачи.
- Ограничиваем задачу десятью уточняющими запросами.
- Показываем историю запросов в прямом порядке.
- Для каждого запроса показываем дату в фиксированном формате, отправленные файлы и реально изменённые файлы.
- Добавляем кнопку копирования для текстов старых уточняющих запросов.
- Показываем условную стоимость: 3 цента за один уточняющий запрос и итоговую стоимость по задаче.

## Impact

- Потребуется расширить структуру истории уточнений.
- Потребуется обновить UI истории и счётчики в верстаке.
