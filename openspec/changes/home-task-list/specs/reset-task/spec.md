## MODIFIED Requirements

### Requirement: Задача поддерживает reset в исходное состояние

Система SHALL позволять выполнить reset задачи со стартовой страницы пользователя.

#### Scenario: Пользователь нажимает `Сбросить` на стартовой странице
- **WHEN** пользователь запускает reset задачи из списка задач
- **THEN** система выполняет тот же reset, что и из лаборатории
- **AND** после успешного reset задача отображается как `Не начиналась`
