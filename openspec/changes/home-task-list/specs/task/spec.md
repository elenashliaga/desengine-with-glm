## MODIFIED Requirements

### Requirement: Система показывает список задач на стартовой странице

Система SHALL показывать на стартовой странице пользователя список всех задач.

Список SHALL быть отсортирован по коду задачи.

#### Scenario: Пользователь открывает корневую страницу
- **WHEN** пользователь открывает `/`
- **THEN** система показывает список всех задач
- **AND** задачи отсортированы по их коду

### Requirement: Строка задачи показывает действия и статус

Система SHALL показывать для каждой задачи в компактной по вертикали строке:
- название задачи;
- текстовый статус задачи;
- либо кнопку `Начать`, либо текущий номер уровня;
- кнопку `Продолжить`;
- горизонтальный индикатор уровня;
- кнопку `Сбросить`.

#### Scenario: Задача ещё не начиналась
- **WHEN** задача находится в состоянии `Не начиналась`
- **THEN** система показывает текстовый статус `Не начиналась`
- **AND** вместо номера уровня система показывает кнопку `Начать`

#### Scenario: Задача уже начата
- **WHEN** задача уже имеет текущий уровень
- **THEN** система показывает текстовый статус с текущим уровнем
- **AND** показывает номер этого уровня
- **AND** показывает кнопку `Продолжить`
- **AND** показывает горизонтальный индикатор уровня

### Requirement: Название задачи ведёт в лабораторию

Система SHALL делать название задачи ссылкой на продолжение её решения в лаборатории.

#### Scenario: Пользователь нажимает на название задачи
- **WHEN** пользователь нажимает на название задачи в списке
- **THEN** система открывает лабораторию этой задачи
