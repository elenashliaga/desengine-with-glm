## MODIFIED Requirements

### Requirement: Итерация использует обязательные входные данные

Система SHALL включать в каждую итерацию:
- все картинки, которые разрешено показывать пользователю на текущем уровне задачи;
- текущий промпт пользователя;
- выбранные пользователем вводные файлы (по умолчанию — все);
- системные промпты (производственные; дидактические уровня — только в обучающем режиме).

#### Scenario: Пользователь запускает итерацию без явного выбора файлов
- **WHEN** пользователь запускает итерацию и не выбирает вводные файлы
- **THEN** система включает в контекст итерации все файлы набора
- **AND** все level-разрешённые картинки текущего уровня

#### Scenario: Пользователь запускает обычное уточнение после старта
- **WHEN** задача уже инициализирована и пользователь отправляет уточняющий промпт
- **THEN** система снова отправляет все картинки, которые разрешено показывать пользователю на текущем уровне задачи
- **AND** использует текстовый контекст из выбранных файлов

### Requirement: Инициирующий запуск уровня использует картинку и все файлы

Система SHALL выполнять скрытый инициирующий запуск каждого уровня с level-разрешёнными картинками задачи, полным набором файлов и системными промптами уровня.

#### Scenario: Система инициирует новый уровень
- **WHEN** пользователь впервые входит в уровень задачи
- **THEN** система отправляет все level-разрешённые картинки задачи
- **AND** отправляет все файлы задачи
- **AND** использует производственный и дидактический промпты уровня

### Requirement: Инициирующий запуск не считается уточняющим промптом

Система SHALL не включать скрытый инициирующий запуск уровня в список уточняющих промптов пользователя и не учитывать его в лимите `maxPromptsPerTask`.

#### Scenario: Пользователь смотрит на историю уточняющих промптов
- **WHEN** система уже выполнила инициирующий запуск уровня
- **THEN** этот запуск не показывается в списке уточнений
- **AND** не уменьшает остаток уточняющих промптов уровня

### Requirement: Инициирующий запуск и уточнения используют одну модель

Система SHALL использовать одну и ту же модель для скрытого инициирующего запуска и для обычных уточняющих запросов.

#### Scenario: Система выполняет инициирующий запуск уровня
- **WHEN** уровень запускается впервые
- **THEN** система использует ту же модель, что и для последующих уточнений

### Requirement: Итерация возвращает обновлённые версии файлов

Система SHALL возвращать результат итерации как обновлённые версии файлов набора (возможно, изменены не все).

#### Scenario: Модель изменила только часть файлов
- **WHEN** итерация вернула изменения только для части файлов
- **THEN** остальные файлы остаются без изменений

### Requirement: Ошибка итерации не разрушает текущее состояние

Система SHALL сохранять текущее состояние задания при ошибке LLM (сеть/лимиты/невалидный ответ) и позволять повторить итерацию.

#### Scenario: Провайдер вернул ошибку
- **WHEN** провайдер LLM вернул ошибку
- **THEN** система не теряет текущее состояние файлов и показывает пользователю понятное сообщение
