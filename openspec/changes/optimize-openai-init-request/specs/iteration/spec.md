## MODIFIED Requirements

### Requirement: Инициирующий запуск уровня использует картинку и все файлы

Система SHALL выполнять скрытый инициирующий запуск каждого уровня с PNG-картинкой задачи, системными промптами уровня и только тем текстовым контекстом, который реально нужен для генерации полного набора рабочих файлов текущего уровня.

Система SHALL избегать избыточного и дублирующегося контекста в initiator-потоке, если этот контекст не влияет на качество результата.

#### Scenario: Пользователь впервые входит в задачу уровня
- **WHEN** система выполняет первый скрытый initiator-запуск задачи
- **THEN** она отправляет PNG-картинку текущего уровня
- **AND** не отправляет фиктивное “текущее состояние всех файлов”, если эти файлы ещё не созданы
- **AND** всё равно ожидает на выходе полный набор рабочих файлов задачи

#### Scenario: Пользователь переходит на новый уровень уже начатой задачи
- **WHEN** система выполняет initiator-запуск нового уровня для существующей задачи
- **THEN** она отправляет только те текущие текстовые файлы, которые действительно нужны для продолжения работы на новом уровне
- **AND** не дублирует в instruction один и тот же смысл в нескольких промпт-слоях без необходимости
- **AND** всё равно ожидает на выходе полный набор рабочих файлов задачи
