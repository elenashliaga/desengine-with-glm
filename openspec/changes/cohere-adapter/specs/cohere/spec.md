## ADDED Requirements

### Requirement: Система поддерживает адаптер Cohere

Система SHALL поддерживать отдельный адаптер для Cohere.

#### Scenario: Оператор выбирает Cohere
- **WHEN** конфигурация приложения переключена на Cohere
- **THEN** система использует адаптер Cohere для LLM-вызовов

### Requirement: Конфигурация Cohere задаётся явно

Система SHALL брать параметры подключения к Cohere из локальной конфигурации приложения.

#### Scenario: Оператор настраивает Cohere
- **WHEN** оператор задаёт обязательные параметры подключения к Cohere
- **THEN** система использует их без изменения кода

### Requirement: Ошибки Cohere различаются по типам

Система SHALL различать как минимум следующие классы ошибок для Cohere:
- неполная конфигурация;
- ошибка авторизации;
- недоступность endpoint;
- таймаут;
- невалидный ответ провайдера.

#### Scenario: Авторизация Cohere не прошла
- **WHEN** провайдер возвращает ошибку авторизации
- **THEN** пользователь видит понятное сообщение об ошибке доступа к Cohere
