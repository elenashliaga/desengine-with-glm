## ADDED Requirements

### Requirement: Редактирование файлов сохраняется автоматически

Система SHALL автоматически сохранять изменённые поля редактирования без отдельной кнопки «Сохранить».

#### Scenario: Пользователь меняет код в одном из полей
- **WHEN** пользователь изменил содержимое редактируемого поля
- **THEN** система помечает активный файл как несохранённый
- **AND** запускает автосохранение не раньше чем через 10 секунд после последнего изменения

#### Scenario: Пользователь ничего не менял
- **WHEN** с момента последнего сохранения содержимое поля не изменялось
- **THEN** система не выполняет повторное сохранение

### Requirement: Несохранённые файлы явно помечаются в интерфейсе

Система SHALL явно показывать, какие именно изменения ещё не были сохранены.

#### Scenario: Пользователь меняет активный файл
- **WHEN** активный файл содержит несохранённые изменения
- **THEN** редактор этого файла получает красную рамку
- **AND** вкладка этого файла показывает заметную красную точку

### Requirement: Явное сохранение сохраняет все несохранённые файлы

Система SHALL поддерживать явное сохранение поверх автосохранения.

#### Scenario: Пользователь нажимает кнопку «Сохранить»
- **WHEN** в задаче есть несколько несохранённых файлов
- **THEN** система сохраняет все несохранённые файлы одним действием
- **AND** после успешного сохранения скрывает кнопку `Сохранить`

#### Scenario: Пользователь нажимает `Cmd+S` или `Ctrl+S`
- **WHEN** в задаче есть несколько несохранённых файлов
- **THEN** система сохраняет все несохранённые файлы

### Requirement: Смена файла и ключевые действия не теряют несохранённые изменения

Система SHALL сначала сохранять pending-изменения перед действиями, которые меняют рабочий контекст задачи.

#### Scenario: Пользователь переключается на другой файл
- **WHEN** текущий файл содержит несохранённые изменения
- **THEN** система сначала сохраняет текущий файл
- **AND** только после этого открывает следующий файл

#### Scenario: Пользователь уходит к списку задач или запускает действие задачи
- **WHEN** у задачи есть несохранённые изменения
- **AND** пользователь открывает список задач уровня, запускает проверку, сброс задачи или уточнение
- **THEN** система сначала сохраняет несохранённые файлы
