## ADDED Requirements

### Requirement: Рискованные render-островки shell-интерфейса предпочитают локальные boundary/fallback-страховки

Система SHALL в product-shell интерфейсе предпочитать локальные boundary/fallback-страховки вокруг рискованных render-островков, если их добавление не вносит заметной архитектурной цены.

#### Scenario: Команда работает с динамическим render-островком
- **WHEN** shell-интерфейс рендерит динамический, пользовательский или иной потенциально нестабильный UI-островок
- **THEN** review проверяет, можно ли почти бесплатно изолировать его локальным boundary/fallback
- **AND** при положительном ответе такой boundary/fallback должен быть добавлен

#### Scenario: Команда оценивает простой статический shell-компонент
- **WHEN** компонент не рендерит рискованное динамическое содержимое
- **THEN** система не требует механически оборачивать его boundary только ради единообразия
