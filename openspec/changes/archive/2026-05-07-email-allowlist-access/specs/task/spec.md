## ADDED Requirements

### Requirement: Доступ к заданиям возможен только после проверки допуска

Система SHALL открывать лабораторию и задания только после успешной проверки допуска пользователя через capability `access-control`.

#### Scenario: Пользователь ещё не прошёл проверку допуска
- **WHEN** пользователь не прошёл проверку допуска
- **THEN** система не показывает лабораторию и не открывает задания

#### Scenario: Пользователь открыл приложение заново
- **GIVEN** пользователь ранее уже проходил проверку допуска
- **WHEN** пользователь открывает приложение заново
- **THEN** система не открывает задания, пока пользователь снова не пройдёт проверку допуска
