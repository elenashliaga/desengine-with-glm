## MODIFIED Requirements

### Requirement: Интерфейс уточнения задачи минимален

Система SHALL предоставлять для уточняющего промпта минимальный интерфейс без ручного выбора файлового контекста.

#### Scenario: Пользователь готовит уточняющий промпт
- **WHEN** пользователь открывает блок уточнения внутри задачи
- **THEN** он видит текстовое поле ввода и действие запуска
- **AND** не видит отдельного UI для выбора файлов итерации
