## MODIFIED Requirements

### Requirement: Итерация использует все разрешённые рабочие файлы текущего уровня

Система SHALL включать в контекст уточняющей итерации все рабочие файлы из набора, разрешённые на текущем уровне.

#### Scenario: Пользователь запускает уточнение
- **WHEN** пользователь запускает очередную итерацию
- **THEN** система автоматически включает в контекст все рабочие файлы, разрешённые на текущем уровне

### Requirement: Пользователь не выбирает вводные файлы вручную

Система SHALL не показывать пользователю отдельный выбор input files для уточняющего промпта.

#### Scenario: Пользователь открывает форму уточняющего промпта
- **WHEN** пользователь взаимодействует с формой `iterate`
- **THEN** интерфейс сводится к вводу текста уточнения и запуску
