## MODIFIED Requirements

### Requirement: Официальные админские операции имеют единый каталог и единый способ запуска

Система SHALL предоставлять канонические административные утилиты локального сопровождения через единый каталог `/tools` и npm-driven запуск.

#### Scenario: Оператор выполняет smoke-check или другую служебную операцию
- **WHEN** оператор использует официальную административную утилиту
- **THEN** он запускает её через `npm run ...`
- **AND** канонический исполняемый файл находится в `/tools`
