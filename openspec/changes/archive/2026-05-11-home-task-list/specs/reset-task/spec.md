## MODIFIED Requirements

### Requirement: Задача поддерживает reset в исходное состояние

Система SHALL позволять выполнить reset задачи со страницы списка задач `/tasks`.

#### Scenario: Пользователь нажимает `Сбросить` на странице списка задач
- **WHEN** пользователь запускает reset начатой задачи из списка задач
- **THEN** система выполняет тот же reset, что и из лаборатории
- **AND** после успешного reset задача отображается как `Не начиналась`
