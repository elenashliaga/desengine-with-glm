## MODIFIED Requirements

### Requirement: Явное сохранение сохраняет все несохранённые файлы

Система SHALL поддерживать явное сохранение поверх автосохранения.

#### Scenario: Пользователь нажимает кнопку «Сохранить»
- **WHEN** в задаче есть несколько несохранённых файлов
- **THEN** система сохраняет все несохранённые файлы одним действием
- **AND** после успешного сохранения скрывает кнопку `Сохранить`

#### Scenario: Пользователь нажимает `Cmd+S` или `Ctrl+S`
- **WHEN** в задаче есть несколько несохранённых файлов
- **THEN** система сохраняет все несохранённые файлы

#### Scenario: Пользователь нажимает `Cmd+S` или `Ctrl+S` внутри редактора кода
- **WHEN** фокус находится внутри редактируемого кодового файла
- **AND** в задаче есть несохранённые изменения
- **THEN** система перехватывает эту горячую клавишу в пользу локального сохранения
- **AND** не отдаёт её дефолтному browser-level сценарию вместо сохранения задачи
