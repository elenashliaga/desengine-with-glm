## ADDED Requirements

### Requirement: Пользователь может явно завершить решение задачи

Система SHALL предоставлять кнопку «Закончить решать задачу», которая переводит задачу в завершённое состояние.

#### Scenario: Пользователь завершает задачу вручную
- **WHEN** пользователь нажимает кнопку «Закончить решать задачу»
- **THEN** система помечает задачу как завершённую

### Requirement: Для завершения уровней подготовлены hidden prompt-файлы проверки

Система SHALL хранить для каждого текущего onboarding-уровня hidden prompt-файл будущей проверки по пути `onboarding/prompts/levels/<levelId>/check.md`.

До реализации полноценного checking flow эти файлы SHALL быть допустимыми данными-заглушками на русском языке.

#### Scenario: Runtime или автор контента ищет prompt проверки уровня
- **WHEN** системе или автору нужен hidden prompt проверки для существующего уровня
- **THEN** файл существует по пути `onboarding/prompts/levels/<levelId>/check.md`
- **AND** содержит заглушечный контракт для будущей LLM-проверки
