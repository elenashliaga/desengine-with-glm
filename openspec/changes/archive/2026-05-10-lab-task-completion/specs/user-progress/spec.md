## ADDED Requirements

### Requirement: Прогресс задачи хранит статус завершения

Система SHALL хранить для каждой задачи статус завершения.

#### Scenario: Задача завершена вручную
- **WHEN** пользователь завершил задачу через интерфейс
- **THEN** в локальном прогрессе задача помечается как завершённая

#### Scenario: Задача завершена автоматически
- **WHEN** задача исчерпала 10 уточняющих запросов
- **THEN** в локальном прогрессе задача также помечается как завершённая
