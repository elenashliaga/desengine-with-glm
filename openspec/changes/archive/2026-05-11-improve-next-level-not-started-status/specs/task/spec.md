## MODIFIED Requirements

### Requirement: Стартовая страница задач показывает статус и действие по каждой задаче

Система SHALL на стартовой странице задач показывать для каждой задачи:
- текстовый статус;
- доступный action (`Начать` или `Продолжить`);
- горизонтальный индикатор уровня;
- кнопку `Сбросить задачу` для начатой задачи.

#### Scenario: Задача ещё не начиналась
- **WHEN** задача находится в состоянии `Не начиналась`
- **THEN** система показывает текстовый статус `Не начиналась`
- **AND** показывает полный доступный лимит уточнений первого уровня
- **AND** показывает кнопку `Начать`
- **AND** не показывает кнопки `Продолжить` и `Сбросить задачу`
- **AND** по нажатию `Начать` открывает задачу на стартовой странице первого уровня

#### Scenario: Задача уже начата
- **WHEN** задача уже имеет текущий уровень
- **THEN** система показывает текущий уровень
- **AND** показывает, сколько уточняющих запросов осталось на текущем уровне
- **AND** показывает кнопку `Продолжить`
- **AND** показывает горизонтальный индикатор уровня
- **AND** показывает кнопку `Сбросить задачу`

#### Scenario: Задача начата, но новый текущий уровень ещё не стартовал
- **WHEN** задача уже проходилась раньше
- **AND** новый текущий уровень ещё не был явно начат
- **THEN** карточка задачи показывает, что задача остаётся начатой
- **AND** явно сообщает, что текущий уровень ещё не начат
- **AND** оставляет действием `Продолжить`, ведущим к стартовой странице этого уровня
