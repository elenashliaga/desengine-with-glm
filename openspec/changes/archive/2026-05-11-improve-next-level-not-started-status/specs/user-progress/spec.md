## MODIFIED Requirements

### Requirement: Прогресс отображается на стартовой странице задач

Система SHALL показывать прогресс пользователя по задачам на стартовой странице.

Для начатой задачи система SHALL показывать текущий уровень, остаток уточняющих запросов на текущем уровне и горизонтальный индикатор, длина которого растёт вместе с уровнем.

#### Scenario: Пользователь открывает стартовую страницу
- **WHEN** у пользователя есть начатые задачи
- **THEN** система показывает для каждой начатой задачи её текущий уровень
- **AND** показывает, сколько уточняющих запросов осталось на текущем уровне
- **AND** показывает горизонтальный индикатор уровня

#### Scenario: Следующий уровень уже стал текущим, но ещё не начат
- **WHEN** пользователь успешно завершил предыдущий уровень
- **AND** ещё не запустил новый текущий уровень
- **THEN** прогресс показывает задачу как начатую
- **AND** одновременно явно отражает, что текущий уровень ещё не начат
- **AND** не показывает этот сценарий как обычную активную работу на новом уровне

#### Scenario: У задачи более высокий уровень
- **WHEN** текущий уровень одной задачи выше, чем у другой
- **THEN** горизонтальный индикатор первой задачи визуально длиннее
