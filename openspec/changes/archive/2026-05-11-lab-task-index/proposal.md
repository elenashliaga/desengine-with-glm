## Why

Пользователю нужен обзор всех задач и их состояния без открытия каждой задачи по отдельности.

## What Changes

- Дорабатываем существующую индекс-страницу `/tasks` со списком задач.
- Для каждой задачи показываем статус завершения и остаток уточняющих запросов на текущем уровне.
- Из списка задач можно перейти на страницу конкретной задачи.

## Impact

- Потребуется агрегировать локальный прогресс по всем задачам.
- Потребуется расширить summary прогресса задачи для списка `/tasks`.
