## MODIFIED Requirements

### Requirement: Задание включает текущее состояние файлов

Система SHALL позволять пользователю публиковать публичный слепок текущего состояния задачи из рабочего экрана.

#### Scenario: Пользователь публикует слепок из рабочего экрана задачи
- **WHEN** пользователь находится в лаборатории задачи
- **AND** у задачи уже есть текущее рабочее состояние
- **THEN** система показывает действие публикации слепка
- **AND** после успешной публикации возвращает публичную ссылку на слепок

#### Scenario: Публикация слепка заблокирована проверкой безопасности
- **WHEN** пользователь публикует слепок задачи
- **AND** система обнаруживает признаки секрета в файлах или промптах
- **THEN** рабочий экран показывает ошибку публикации
- **AND** не создаёт публичный слепок
