## MODIFIED Requirements

### Requirement: Состав слепка на MVP фиксирован

Система SHALL публиковать слепок как отдельный публичный ресурс с фиксированным JSON-составом.

Слепок SHALL включать:
- итоговые текстовые файлы набора компонента;
- историю промптов пользователя по заданию в порядке выполнения.

Слепок SHALL не включать:
- системные и производственные промпты;
- progress-метаданные пользователя;
- runtime-конфиг и переменные окружения;
- внутреннюю LLM-телеметрию и секреты.

#### Scenario: Пользователь публикует слепок
- **WHEN** пользователь публикует слепок задания
- **THEN** система создаёт отдельный публичный слепок
- **AND** слепок содержит итоговые файлы + историю промптов
- **AND** пользователь получает публичную ссылку на этот слепок

#### Scenario: Пользователь открывает публичную ссылку слепка
- **WHEN** пользователь открывает опубликованный маршрут слепка
- **THEN** система показывает содержимое файлов и историю промптов для этого `snapshotId`

### Requirement: Слепок не содержит секреты

Система SHALL проверять содержимое итоговых файлов и истории промптов перед публикацией слепка.

При обнаружении признаков секрета система SHALL блокировать публикацию по умолчанию и возвращать понятную ошибку без раскрытия самого секрета.

#### Scenario: В промпте или файле найден секрет
- **WHEN** пользователь запускает публикацию слепка
- **AND** в итоговых файлах или истории промптов найдены признаки API-ключа, токена или приватного секрета
- **THEN** система не публикует слепок
- **AND** сообщает, что перед публикацией нужно удалить секрет из задачи

#### Scenario: В окружении настроен ключ API
- **WHEN** пользователь публикует слепок
- **THEN** данные окружения не попадают в слепок

### Requirement: Публикация слепка доступна только для начатой задачи

Система SHALL разрешать публикацию слепка только для задания, у которого уже есть пользовательское рабочее состояние.

#### Scenario: Пользователь пытается публиковать не начатую задачу
- **WHEN** задача ещё не была запущена
- **THEN** система не публикует слепок
- **AND** сообщает, что сначала нужно начать задачу
