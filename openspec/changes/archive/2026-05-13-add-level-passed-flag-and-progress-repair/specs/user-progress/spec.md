## ADDED Requirements

### Requirement: Прогресс уровня хранит явный признак прохождения

Система SHALL хранить в прогрессе каждого уровня задачи явное булево поле `isPassed`, отражающее факт прохождения уровня.

#### Scenario: Уровень успешно проверен
- **WHEN** содержательная проверка уровня завершилась успешно
- **THEN** уровень помечается как `isPassed = true`
- **AND** уровень имеет статус `completed`

### Requirement: Система восстанавливает прохождение уровня из persisted данных

Система SHALL при чтении локального прогресса уметь восстановить пройденность уровня, если она подтверждается сохранёнными артефактами проверки.

#### Scenario: В check-result есть успешное прохождение
- **WHEN** у задачи есть `check-result` с `passed=true` и `kind=passed`
- **THEN** соответствующий уровень помечается как пройденный (`isPassed=true`, `status=completed`)
- **AND** текущий уровень задачи продвигается до следующего после пройденного
