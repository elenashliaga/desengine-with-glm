## MODIFIED Requirements

### Requirement: Корневой маршрут открывает публичную страницу состояния системы

Система SHALL использовать `/` как публичную точку входа со страницей состояния системы, а не как redirect на список задач.

#### Scenario: Пользователь открывает корень продукта до допуска
- **WHEN** пользователь открывает `/`
- **THEN** система показывает публичную страницу состояния
- **AND** не перенаправляет пользователя на `/tasks`

#### Scenario: Пользователь уже получил допуск и снова открывает корень продукта
- **WHEN** пользователь с валидным allowlist-допуском открывает `/`
- **THEN** система всё равно показывает публичную страницу состояния
- **AND** список задач остаётся доступен на `/tasks`
