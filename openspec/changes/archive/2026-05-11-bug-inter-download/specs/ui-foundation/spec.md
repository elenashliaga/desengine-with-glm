## ADDED Requirements

### Requirement: Базовый UI-шрифт Inter доступен локально для production build

Система SHALL хранить canonical UI-шрифт Inter в репозитории как локальные font assets для product-shell интерфейса, чтобы production build не зависел от внешнего скачивания шрифта во время сборки.

Локальная поставка SHALL сохранять текущий UI-контракт:
- базовым UI-шрифтом остаётся именно Inter;
- Tailwind-слой продолжает обращаться к шрифту через переменную `--font-ui`;
- системные fallback-шрифты могут использоваться только как fallback, а не как замена Inter.

#### Scenario: Production build выполняется без доступа к `fonts.gstatic.com`
- **WHEN** среда сборки не может обратиться к внешнему хосту Google Fonts
- **THEN** production build продолжает собирать приложение без ошибки загрузки Inter
- **AND** итоговый UI-контракт по шрифту остаётся основанным на Inter

#### Scenario: Разработчик проверяет подключение базового UI-шрифта
- **WHEN** product-shell интерфейс использует переменную `--font-ui`
- **THEN** эта переменная ссылается на локально поставляемый Inter
- **AND** подключение шрифта не требует сетевого скачивания во время build
