## ADDED Requirements

### Requirement: PNG обязателен для инициирующего запуска задания

Система SHALL требовать PNG‑картинку компонента как обязательную часть задания для инициирующего запуска.

#### Scenario: Пользователь пытается запустить итерацию без PNG
- **WHEN** PNG отсутствует
- **THEN** система не выполняет инициирующий запуск и сообщает об ошибке

### Requirement: Если над заданием ещё не работали, система предлагает начать

Если в каталоге задания отсутствует `Component.tsx`, система SHALL показывать пользователю фазу “Начало работы над задачей” с предложением начать.

#### Scenario: Пользователь открывает новое задание без Component.tsx
- **WHEN** пользователь открывает задание, в каталоге которого нет `Component.tsx`
- **THEN** система показывает экран “Вы ещё не работали над этой задачей. Начать?” и кнопку “Да, начать”
