## ADDED Requirements

### Requirement: На MVP используется ChatGPT API по ключу

Система SHALL использовать ChatGPT API как единственный LLM‑провайдер на MVP.

#### Scenario: Пользователь запускает итерацию на MVP
- **WHEN** пользователь запускает итерацию
- **THEN** система отправляет запрос в ChatGPT API

### Requirement: Ключ не попадает в слепки и репозиторий

Система SHALL хранить и использовать ключ так, чтобы он не попадал:
- в публичные слепки,
- в репозиторий,
- в пользовательские сообщения об ошибках по умолчанию.

#### Scenario: Пользователь публикует слепок
- **WHEN** пользователь публикует слепок
- **THEN** ключ не включается в слепок

### Requirement: Учёт затрат ведётся на итерацию и на задание

Система SHALL вести учёт затрат минимум на уровне:
- итерация (один запуск),
- задание (сумма по итерациям).

#### Scenario: Пользователь выполнил несколько итераций
- **WHEN** пользователь выполнил несколько итераций в рамках задания
- **THEN** система показывает агрегированные затраты по заданию
