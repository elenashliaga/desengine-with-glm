## MODIFIED Requirements

### Requirement: Задание включает текущее состояние файлов

Система SHALL делать кодовую панель рабочим локальным инструментом, а не тяжёлой навигацией между mini-pages.

#### Scenario: Пользователь переключается между файлами задачи
- **WHEN** пользователь меняет активный файл
- **THEN** система переключает кодовую панель локально
- **AND** не возвращает пользователя в верх страницы
- **AND** не создаёт ощущение полной перезагрузки task-экрана

### Requirement: Пользователь открывает редактируемый файл

Система SHALL поддерживать дополнительные действия над кодом и спокойный visual tone редактора.

#### Scenario: Пользователь работает с кодом задачи
- **WHEN** пользователь смотрит и редактирует код
- **THEN** система предоставляет явное действие `Скопировать`
- **AND** не навязывает тяжёлый чёрный фон как единственный обязательный вариант
