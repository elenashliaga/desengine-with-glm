## MODIFIED Requirements

### Requirement: Внешний локальный сценарий различает project data и user state

Система SHALL в официальном локальном сценарии различать versioned проектные данные и пользовательское состояние.

#### Scenario: Пользователь обновляет проект локально из GitHub
- **WHEN** пользователь обновляет код и project data
- **THEN** user-owned каталог `/user` не считается частью обновляемого project payload

### Requirement: Отсутствие user state не ломает первый запуск

Система SHALL позволять запуск с пустым или отсутствующим `/user`.

#### Scenario: Пользователь впервые запускает продукт
- **WHEN** каталога `/user` ещё нет
- **THEN** система всё равно запускается штатно
- **AND** создаёт user-owned состояние только по мере необходимости

#### Scenario: Пользователь удалил каталог `/user`
- **WHEN** пользователь полностью удалил `/user`
- **THEN** система запускается как после полного сброса пользовательских результатов
- **AND** не требует ручного восстановления project data
