## MODIFIED Requirements

### Requirement: Задание включает текущее состояние файлов

Система SHALL хранить текущее состояние набора файлов компонента как часть задания и SHALL показывать список всех задач на стартовой странице пользователя.

#### Scenario: Пользователь возвращается к заданию позже
- **WHEN** пользователь открывает ранее начатое задание
- **THEN** система показывает текущее состояние файлов из user-owned рабочего состояния задачи

### Requirement: Project data задачи и пользовательские результаты разделены

Система SHALL хранить task metadata и базовые референсы как project-owned данные, а рабочие файлы и runtime-результаты пользователя как user-owned данные.

#### Scenario: Система читает описание задачи
- **WHEN** системе нужны базовые настройки и референсы задачи
- **THEN** она читает их из project-owned каталога задачи

#### Scenario: Система читает рабочее состояние задачи
- **WHEN** системе нужны текущие рабочие файлы, созданные пользователем
- **THEN** она читает их из user-owned пространства внутри `/user`

### Requirement: Сброс задачи не должен удалять project-owned данные

Система SHALL при пользовательском reset удалять только user-owned результаты задачи.

#### Scenario: Пользователь сбрасывает задачу
- **WHEN** пользователь выполняет reset задачи
- **THEN** система очищает только user-owned рабочие файлы и runtime-историю этой задачи
- **AND** не удаляет project-owned конфиг и базовые референсы задачи
