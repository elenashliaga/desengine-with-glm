## MODIFIED Requirements

### Requirement: Прогресс пользователя хранится отдельно от project data

Система SHALL хранить реальный прогресс пользователя в user-owned каталоге, а не рядом с versioned проектной конфигурацией.

#### Scenario: Система читает прогресс пользователя
- **WHEN** системе нужен текущий прогресс пользователя
- **THEN** она читает его из user-owned хранилища внутри `/user`

#### Scenario: У пользовательского хранилища ещё нет прогресса
- **WHEN** файл прогресса отсутствует
- **THEN** система трактует это как отсутствие начатых задач

### Requirement: Удаление user state сбрасывает прогресс в ноль

Система SHALL трактовать отсутствие пользовательского каталога как полностью сброшенное состояние.

#### Scenario: Каталог `/user` был удалён целиком
- **WHEN** приложение запускается после полного удаления `/user`
- **THEN** система не падает
- **AND** считает все задачи не начатыми
- **AND** пересоздаёт нужные user-owned данные по мере работы
