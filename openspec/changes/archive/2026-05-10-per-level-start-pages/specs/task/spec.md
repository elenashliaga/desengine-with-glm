## MODIFIED Requirements

### Requirement: Каждый уровень задачи начинается со своей стартовой страницы

Система SHALL предоставлять для каждого уровня задачи, включая первый, отдельную стартовую страницу начала работы над этим уровнем.

#### Scenario: Пользователь впервые открывает первый уровень задачи
- **WHEN** пользователь открывает задачу на первом уровне
- **AND** первый уровень ещё не начат
- **THEN** система показывает стартовую страницу этого уровня

#### Scenario: Пользователь переходит на новый уровень задачи
- **WHEN** предыдущий уровень завершён
- **AND** следующий уровень ещё не начат
- **THEN** система показывает стартовую страницу следующего уровня

### Requirement: Стартовая страница уровня показывается только один раз

Система SHALL показывать стартовую страницу уровня только до первого явного начала этого уровня.

#### Scenario: Пользователь возвращается на уже начатый уровень
- **WHEN** уровень уже был начат
- **AND** ещё не завершён
- **THEN** система открывает рабочий экран уровня
- **AND** не показывает стартовую страницу повторно

### Requirement: Явное начало уровня запускает hidden start-flow

Система SHALL связывать начало уровня с явным пользовательским действием на стартовой странице этого уровня.

#### Scenario: Пользователь начинает уровень
- **WHEN** пользователь нажимает действие начала уровня на его стартовой странице
- **THEN** система выполняет hidden start-запуск уровня
- **AND** после этого переводит пользователя в рабочий экран уровня

### Requirement: Следующий уровень открывается без обязательного промежуточного task-экрана

Система SHALL после успешной проверки уровня и появления следующего уровня открывать задачу сразу на новом текущем уровне, без обязательного отдельного промежуточного task-экрана между ними.

#### Scenario: У задачи есть следующий уровень
- **WHEN** пользователь подтверждает переход после успешной проверки уровня
- **THEN** система открывает задачу на следующем текущем уровне
- **AND** показывает стартовую страницу этого уровня, если он ещё не начат
