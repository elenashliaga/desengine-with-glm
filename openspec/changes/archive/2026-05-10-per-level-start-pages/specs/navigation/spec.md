## MODIFIED Requirements

### Requirement: Переход между уровнями не требует отдельного пользовательского path

Система SHALL не требовать отдельный пользовательский path для обязательного transition-screen между уровнями одной и той же задачи.

#### Scenario: Пользователь завершил текущий уровень задачи
- **WHEN** пользователь подтверждает переход после успешной проверки уровня
- **THEN** система может открыть канонический адрес самой задачи `/tasks/<taskId>`
- **AND** не обязана показывать отдельный экран по адресу `/tasks/<taskId>/next`

#### Scenario: Пользователь открывает legacy-маршрут следующего уровня
- **WHEN** пользователь открывает `/tasks/<taskId>/next`
- **THEN** система может перенаправить его на `/tasks/<taskId>`
