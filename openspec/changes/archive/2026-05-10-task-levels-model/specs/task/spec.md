## ADDED Requirements

### Requirement: Задача обязана хранить свой максимальный уровень

Система SHALL хранить у каждой задачи явное значение `maxLevel`.

#### Scenario: Система читает метаданные задачи
- **WHEN** система загружает задачу
- **THEN** из метаданных задачи известен её максимальный уровень `maxLevel`

### Requirement: Задача поддерживает отдельный экран полного завершения

Система SHALL предоставлять отдельный маршрут `/tasks/<taskId>/done` для экрана полного завершения задачи.

#### Scenario: Пользователь открывает экран полного завершения задачи
- **WHEN** пользователь открывает `/tasks/<taskId>/done`
- **THEN** система показывает отдельный экран, что задача завершена целиком
