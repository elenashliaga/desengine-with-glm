## ADDED Requirements

### Requirement: Итерации ограничиваются лимитом уровня

Система SHALL учитывать лимит промптов уровня при выполнении итераций по задаче.

#### Scenario: Пользователь ещё не достиг лимита
- **WHEN** число использованных промптов меньше `maxPromptsPerTask`
- **THEN** система разрешает новую итерацию

#### Scenario: Пользователь достиг лимита
- **WHEN** число использованных промптов равно `maxPromptsPerTask`
- **THEN** система не разрешает новую итерацию как часть этой задачи уровня

#### Scenario: Лимит итераций исчерпан, но уровень ещё не завершён
- **WHEN** число использованных промптов равно `maxPromptsPerTask`
- **AND** уровень ещё не прошёл успешную проверку результата
- **THEN** система сохраняет уровень как не завершённый
- **AND** не открывает следующий уровень автоматически

### Requirement: Технический сбой проверки не расходует лимит содержательных проверок

Система SHALL не учитывать технический сбой checking run как содержательную попытку проверки уровня.

#### Scenario: Проверка завершилась технической ошибкой
- **WHEN** checking run не вернул содержательный результат из-за технической ошибки
- **THEN** система не увеличивает число использованных содержательных проверок уровня
- **AND** сохраняет возможность повторить проверку
