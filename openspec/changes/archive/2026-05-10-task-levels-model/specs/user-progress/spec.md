## ADDED Requirements

### Requirement: Прогресс хранит статус задачи на уровне

Система SHALL хранить статус прохождения задачи пользователем с учётом её уровня.

#### Scenario: Пользователь начал задачу
- **WHEN** пользователь приступил к задаче
- **THEN** система сохраняет статус задачи на её уровне как минимум в состоянии `in_progress`

#### Scenario: Пользователь успешно завершил задачу
- **WHEN** задача успешно прошла проверку результата уровня
- **THEN** система сохраняет статус задачи на её уровне как `completed`

#### Scenario: Проверка завершилась техническим сбоем
- **WHEN** checking run завершился техническим сбоем
- **THEN** система не переводит уровень в `completed`
- **AND** сохраняет отдельный checking-state для повторной проверки

### Requirement: Прогресс хранит текущий уровень пользователя внутри задачи

Система SHALL хранить для каждой задачи текущий уровень, на котором находится пользователь.

#### Scenario: Пользователь перешёл на следующий уровень задачи
- **WHEN** пользователь успешно завершил задачу на уровне `L`, и для задачи существует уровень `L+1`
- **THEN** система сохраняет, что текущим уровнем этой задачи становится `L+1`

### Requirement: Прогресс хранит ограничения и checking-state текущего уровня

Система SHALL хранить для текущего уровня число использованных уточняющих промптов, число содержательных проверок и checking-state.

#### Scenario: Пользователь делает уточняющие промпты на уровне
- **WHEN** пользователь работает на текущем уровне
- **THEN** система знает, сколько уточняющих промптов уже использовано на этом уровне

#### Scenario: Пользователь запускает проверку результата уровня
- **WHEN** checking run даёт содержательный результат
- **THEN** система знает, сколько содержательных проверок уже использовано на этом уровне

#### Scenario: Пользователь исчерпал лимит содержательных проверок
- **WHEN** последняя доступная содержательная проверка завершилась неуспешно
- **THEN** система сбрасывает задачу
- **AND** следующий вход в задачу проходит как для состояния `Не начиналась`
