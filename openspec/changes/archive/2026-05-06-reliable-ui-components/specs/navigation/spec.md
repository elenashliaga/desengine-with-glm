## MODIFIED Requirements

### Requirement: Страницы config и help существуют как отдельные top-level маршруты

Система SHALL предоставлять отдельные top-level страницы `/config` и `/help`.

#### Scenario: Пользователь открывает страницу конфигурации
- **WHEN** пользователь открывает `/config`
- **THEN** система показывает страницу конфигурации и статусов подключения
- **AND** навигационные элементы этого интерфейса используют канонические framework-компоненты маршрутизации в соответствии с `ui-foundation`

#### Scenario: Пользователь открывает страницу помощи
- **WHEN** пользователь открывает `/help`
- **THEN** система показывает отдельную страницу помощи
- **AND** навигационные элементы этого интерфейса используют канонические framework-компоненты маршрутизации в соответствии с `ui-foundation`
