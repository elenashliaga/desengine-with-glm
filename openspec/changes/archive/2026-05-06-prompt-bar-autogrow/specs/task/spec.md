## MODIFIED Requirements

### Requirement: Экран задачи использует закреплённую нижнюю prompt-полосу

Система SHALL отображать уточняющий prompt composer как нижнюю полосу, закреплённую у нижнего края экрана задачи.

#### Scenario: Пользователь прокручивает содержимое задачи
- **WHEN** основной контент task-экрана становится длиннее высоты viewport
- **THEN** основной контент скроллится
- **AND** нижняя prompt-полоса остаётся закреплённой у нижнего края экрана

#### Scenario: Пользователь открывает экран задачи
- **WHEN** task-экран отрисован
- **THEN** prompt composer визуально отделён от основной области как нижняя полоса на чёрном фоне

### Requirement: Prompt composer не участвует в основном scroll-контейнере

Система SHALL отделять prompt composer от основной scrollable области task-экрана.

#### Scenario: Task-экран показывает историю, статусы и composer
- **WHEN** пользователь взаимодействует с экраном задачи
- **THEN** история, статусы и прочий основной контент могут прокручиваться независимо
- **AND** prompt composer остаётся в собственной не-scrollable нижней области
