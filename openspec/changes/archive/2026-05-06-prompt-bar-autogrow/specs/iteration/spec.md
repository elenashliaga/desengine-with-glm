## MODIFIED Requirements

### Requirement: Уточняющий промпт использует composer-поле с автоподрастанием

Система SHALL использовать для уточняющего промпта composer-поле, которое в исходном состоянии вмещает одну строку и автоматически растёт по вертикали по мере ввода многострочного текста.

#### Scenario: Пользователь начинает вводить короткое уточнение
- **WHEN** пользователь открывает composer уточняющего промпта
- **THEN** поле ввода отображается в однострочном стартовом состоянии

#### Scenario: Пользователь вводит многострочный текст
- **WHEN** пользователь добавляет переносы строки или текст перестаёт помещаться в одну строку
- **THEN** composer-поле автоматически увеличивается по вертикали

### Requirement: Уточняющий промпт поддерживает keyboard-submit

Система SHALL поддерживать клавиатурную отправку уточняющего промпта и отдельную комбинацию для ручного переноса строки.

#### Scenario: Пользователь нажимает Enter в непустом поле
- **WHEN** composer доступен для ввода
- **AND** поле содержит непустой текст
- **AND** пользователь нажимает `Enter`
- **THEN** система отправляет уточняющий запрос

#### Scenario: Пользователь нажимает Enter в пустом поле
- **WHEN** composer доступен для ввода
- **AND** поле не содержит текста для отправки
- **AND** пользователь нажимает `Enter`
- **THEN** система не отправляет пустой запрос

#### Scenario: Пользователь нажимает Shift+Enter
- **WHEN** composer доступен для ввода
- **AND** пользователь нажимает `Shift+Enter`
- **THEN** в поле вставляется перенос строки
- **AND** запрос не отправляется

### Requirement: Кнопка запуска встроена в composer-ряд

Система SHALL размещать кнопку `Запустить →` справа от composer-поля в одном нижнем ряду ввода.

#### Scenario: Пользователь видит composer уточняющего промпта
- **WHEN** task-экран отображает нижний composer
- **THEN** кнопка `Запустить →` находится справа от поля ввода
- **AND** остаётся доступной как альтернативный способ отправки
