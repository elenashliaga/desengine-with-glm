## MODIFIED Requirements

### Requirement: Система показывает список задач на стартовой странице

Система SHALL показывать список задач только после успешного допуска в лабораторию, а до допуска использовать корневой маршрут `/` как общую страницу состояния системы.

#### Scenario: Пользователь впервые открывает локально поднятый продукт
- **WHEN** пользователь открывает корневой маршрут `/`
- **THEN** система показывает общую страницу состояния системы как основной пользовательский вход
- **AND** этот сценарий описан в официальной инструкции запуска

#### Scenario: Пользователь уже прошёл успешный допуск
- **WHEN** пользователь открывает приложение после allowlist-проверки
- **THEN** система показывает стартовую страницу задач
