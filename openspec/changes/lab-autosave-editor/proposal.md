## Why

Текущий UX редактирования в рабочем экране задачи слишком ручной: кнопка сохранения мешает потоку работы, а поля без подсветки синтаксиса и без признака несохранённых изменений делают редактирование менее удобным.

## What Changes

- Кнопка `Сохранить` появляется только когда в текущем файле есть несохранённые изменения.
- Добавляем автосохранение только для реально изменённых полей с задержкой около 10 секунд.
- Несохранённые поля помечаются красной рамкой.
- Поля кода переводятся на контрол с подсветкой синтаксиса.
- Переключение между файлами автоматически сохраняет текущий изменённый файл.
- `Cmd+S` / `Ctrl+S` запускает сохранение текущего файла.

## Impact

- Потребуется хранить dirty-state и таймеры автосохранения.
- Потребуется заменить текущий контрол редактирования кода.
- Потребуется поддержать явное сохранение как поверх автосохранения, а не вместо него.
