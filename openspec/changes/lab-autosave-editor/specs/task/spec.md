## ADDED Requirements

### Requirement: Редактирование файлов сохраняется автоматически

Система SHALL автоматически сохранять изменённые поля редактирования без отдельной кнопки «Сохранить».

#### Scenario: Пользователь меняет код в одном из полей
- **WHEN** пользователь изменил содержимое редактируемого поля
- **THEN** система помечает это поле как несохранённое красной рамкой
- **AND** запускает автосохранение не раньше чем через 30 секунд после последнего изменения

#### Scenario: Пользователь ничего не менял
- **WHEN** с момента последнего сохранения содержимое поля не изменялось
- **THEN** система не выполняет повторное сохранение

### Requirement: Поля кода используют контрол с подсветкой синтаксиса

Система SHALL отображать редактируемые поля кода через контрол, поддерживающий подсветку синтаксиса.

#### Scenario: Пользователь редактирует файл компонента
- **WHEN** пользователь открывает кодовый файл в верстаке
- **THEN** поле редактирования показывает код с подсветкой синтаксиса

### Requirement: Предпросмотр компонента показывается без декоративной рамки

Система SHALL отображать свёрстанный компонент без дополнительной рамки вокруг области рендера.

#### Scenario: Пользователь смотрит на результат рендера
- **WHEN** справа показан свёрстанный компонент
- **THEN** вокруг результата не отображается дополнительная рамка-контейнер
