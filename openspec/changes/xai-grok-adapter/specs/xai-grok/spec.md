## ADDED Requirements

### Requirement: Система поддерживает адаптер xAI Grok

Система SHALL поддерживать отдельный адаптер для xAI Grok.

#### Scenario: Оператор выбирает xAI Grok
- **WHEN** конфигурация приложения переключена на xAI Grok
- **THEN** система использует адаптер xAI Grok для LLM-вызовов

### Requirement: Конфигурация xAI Grok задаётся явно

Система SHALL брать параметры подключения к xAI Grok из локальной конфигурации приложения.

#### Scenario: Оператор настраивает xAI Grok
- **WHEN** оператор задаёт обязательные параметры подключения к xAI Grok
- **THEN** система использует их без изменения кода

### Requirement: Ошибки xAI Grok различаются по типам

Система SHALL различать как минимум следующие классы ошибок для xAI Grok:
- неполная конфигурация;
- ошибка авторизации;
- недоступность endpoint;
- таймаут;
- невалидный ответ провайдера.

#### Scenario: Авторизация xAI Grok не прошла
- **WHEN** провайдер возвращает ошибку авторизации
- **THEN** пользователь видит понятное сообщение об ошибке доступа к xAI Grok
