## MODIFIED Requirements

### Requirement: Каталог уровня хранит только открытые материалы

Система SHALL не превращать рабочий экран задачи в дубликат общего описания уровня, если пользователю уже доступны task-specific детали.

#### Scenario: Пользователь открыл задачу внутри уровня
- **WHEN** задача имеет собственные пользовательские детали текущего уровня
- **THEN** рабочий экран задачи показывает именно их
- **AND** не дублирует рядом общее описание уровня

### Requirement: Описание уровня не дублируется со скрытыми prompt-материалами

Система SHALL держать preview-зону рабочей лаборатории визуально чистой и без лишних технических подписей.

#### Scenario: Пользователь видит референс и результат
- **WHEN** рабочий экран задачи показывает preview-блок
- **THEN** система не показывает техническое имя файла референса
- **AND** не оборачивает область результата лишней рамкой, если она не несёт отдельного смысла
