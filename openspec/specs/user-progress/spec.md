# Пользователь и прогресс

На MVP система ориентирована на локальную работу одного пользователя на своей машине.

## Purpose

Зафиксировать, что такое “пользователь” и “прогресс” на MVP, и какие данные прогресса считаются локальными и непубличными по умолчанию.

## Requirements

### Requirement: На MVP пользователь локальный и один

Система SHALL поддерживать локальную работу одного пользователя на одной машине на MVP.

#### Scenario: Пользователь использует систему локально
- **WHEN** пользователь работает с заданиями
- **THEN** система не требует аккаунта/серверной регистрации на MVP

### Requirement: Прогресс хранится локально

Система SHALL хранить прогресс локально и не публиковать его автоматически.

#### Scenario: Пользователь публикует слепок
- **WHEN** пользователь публикует слепок задания
- **THEN** прогресс по умолчанию не обязан входить в публикацию

### Requirement: Прогресс отображается на стартовой странице задач

Система SHALL показывать прогресс пользователя по задачам на стартовой странице.

Для начатой задачи система SHALL показывать текущий уровень и горизонтальный индикатор, длина которого растёт вместе с уровнем.

#### Scenario: Пользователь открывает стартовую страницу
- **WHEN** у пользователя есть начатые задачи
- **THEN** система показывает для каждой начатой задачи её текущий уровень
- **AND** показывает горизонтальный индикатор уровня

#### Scenario: У задачи более высокий уровень
- **WHEN** текущий уровень одной задачи выше, чем у другой
- **THEN** горизонтальный индикатор первой задачи визуально длиннее

### Requirement: Reset возвращает задачу в состояние `Не начиналась`

Система SHALL уметь возвращать задачу в состояние `Не начиналась` после reset.

#### Scenario: Пользователь сбрасывает задачу
- **WHEN** reset задачи завершён
- **THEN** система считает эту задачу не начатой
- **AND** следующий вход в задачу проходит обычный стартовый сценарий

## Прогресс (что это)

“Метаданные прогресса” — это служебная информация о том, как пользователь продвигается по заданиям.

Примеры метаданных (не все обязательны на MVP):
- статус задания: не начато / в работе / завершено;
- номер последней итерации;
- дата/время последней активности;
- заметка пользователя (опционально);
- ссылки на опубликованные слепки (если есть).
- текущий уровень пользователя внутри задачи;
- статус текущего уровня задачи;
- число использованных промптов на текущем уровне.

## Требования (MVP)

- Прогресс хранится локально.
- Прогресс не виден другим пользователям (так как других пользователей на MVP нет).
- Публикация слепка не обязана публиковать прогресс (прогресс может публиковаться отдельно, если решим).
- Прогресс должен хранить для каждой задачи текущий уровень, статус уровня и число использованных промптов на этом уровне.

2. Нужен ли экспорт/импорт прогресса между машинами?
