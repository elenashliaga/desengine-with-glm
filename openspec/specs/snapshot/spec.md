# Слепок (Snapshot)

Слепок — публично публикуемый пакет результатов работы пользователя по конкретному заданию.

## Purpose

Определить, что именно публикуется в публичном слепке задания и какие ограничения безопасности действуют по умолчанию.

## Requirements

### Requirement: Состав слепка на MVP фиксирован

Система SHALL включать в слепок:
- итоговые файлы набора компонента;
- историю промптов пользователя по заданию.

#### Scenario: Пользователь публикует слепок
- **WHEN** пользователь публикует слепок задания
- **THEN** слепок содержит итоговые файлы + историю промптов

### Requirement: Слепок не содержит секреты

Система SHALL предотвращать попадание секретов (ключи API, токены, приватные параметры окружения) в слепок по умолчанию.

#### Scenario: В окружении есть ключ API
- **WHEN** в окружении настроен ключ API
- **THEN** ключ не попадает в слепок

## Состав слепка (MVP)

Слепок включает:
- итоговые файлы набора компонента (см. `openspec/specs/component-file-set/spec.md`);
- историю промптов пользователя для этого задания (все промпты в порядке выполнения).

## Требования безопасности (MVP)

- Слепок не должен содержать секреты (ключи API, токены, приватные параметры окружения).
- Система должна предотвращать публикацию секрета по умолчанию:
  - либо исключением известных мест хранения,
  - либо явной проверкой/предупреждением перед публикацией.

## Открытые вопросы

1. Входит ли PNG‑картинка задания в слепок?
2. Входит ли системный промпт (производственный/дидактический) в слепок?
3. Нужны ли подписи версий/идентификаторы итераций в истории промптов (например, timestamp)?
