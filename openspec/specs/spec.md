# AI трансформатор (desengine)

Инструмент, который помогает превращать **картинки (PNG) интерфейсного компонента** в **набор файлов React‑компонента** (код + истории Storybook), через итеративную работу с LLM.

Этот файл — “входная вики‑страница” спецификаций: здесь только обзор, термины и ссылки на более маленькие спеки.

## Статус и ближайшая цель

Ближайшая цель: поддерживать работающий MVP с **настраиваемым сетевым LLM-провайдером по ключу**.

## Термины (кратко)

- **Задание (Task)** — набор PNG-картинок + набор файлов компонента.
- **Корневая страница состояния** — публичный экран `/`, на котором пользователь видит общую диагностику системы и следующие шаги до допуска.
- **Стартовая страница задач** — защищённый экран `/tasks`, на котором пользователь видит все задачи, их прогресс и основные действия.
- **Страница допуска** — экран `/auth`, на котором пользователь проходит allowlist-проверку перед входом в защищённую часть продукта.
- **Уровень задачи (Task Level)** — глобальный уровень обучения, на котором пользователь проходит ту же самую задачу.
- **Лаборатория уровня (Level Lab)** — конкретный рабочий экран уровня: набор картинок, доступных файлов и редактор для этого уровня задачи.
- **Верстак (Workbench)** — место, где открыто одно задание и выполняются итерации.
- **Итерация (Iteration)** — один запуск LLM по промпту пользователя.
- **Промпты** — пользовательские + системные (производственные/дидактические).
- **Слепок (Snapshot)** — публично публикуемый пакет: итоговые файлы + история промптов (без секретов).

## Общее описание системы (вики-уровень)

1. Пользователь открывает `/`, видит общую страницу состояния системы и понимает, что уже готово для работы.
2. После успешного допуска пользователь открывает `/tasks` и выбирает задание из общего списка.
3. Система ведёт итерации: промпт пользователя + выбранные вводные файлы → обновлённые файлы набора.
4. После каждой итерации пользователь видит картинку, текущие файлы и результат рендера.
5. Пользователь может опубликовать слепок (файлы + промпты).
