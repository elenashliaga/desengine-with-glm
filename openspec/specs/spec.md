# AI трансформатор (desengine)

Инструмент, который помогает превращать **картинки (PNG) интерфейсного компонента** в **набор файлов React‑компонента** (код + истории Storybook), через итеративную работу с LLM.

Этот файл — “входная вики‑страница” спецификаций: здесь только обзор, термины и ссылки на более маленькие спеки.

## Статус и ближайшая цель

Ближайшая цель: поддерживать работающий MVP с **настраиваемым сетевым LLM-провайдером по ключу**.

## Термины (кратко)

- **Задание (Task)** — набор PNG-картинок + набор файлов компонента.
- **Стартовая страница задач** — корневой экран `/`, на котором пользователь видит все задачи, их прогресс и основные действия.
- **Уровень задачи (Task Level)** — глобальный уровень обучения, на котором пользователь проходит ту же самую задачу.
- **Верстак (Workbench)** — место, где открыто одно задание и выполняются итерации.
- **Итерация (Iteration)** — один запуск LLM по промпту пользователя.
- **Промпты** — пользовательские + системные (производственные/дидактические).
- **Слепок (Snapshot)** — публично публикуемый пакет: итоговые файлы + история промптов (без секретов).

## Общее описание системы (вики-уровень)

1. Пользователь открывает стартовую страницу `/` и выбирает задание из общего списка.
2. Система ведёт итерации: промпт пользователя + выбранные вводные файлы → обновлённые файлы набора.
3. После каждой итерации пользователь видит картинку, текущие файлы и результат рендера.
4. Пользователь может опубликовать слепок (файлы + промпты).
