# Локальный endpoint LLM

## Purpose

Зафиксировать, что на текущем MVP локальные LLM endpoint'ы не поддерживаются.

## Requirements

### Requirement: Локальные LLM endpoint'ы отключены

Система SHALL не поддерживать локальные модели и локальные URL-ориентированные LLM endpoint'ы в рабочем пользовательском потоке.

#### Scenario: Оператор пытается настроить локальный endpoint
- **WHEN** оператор рассчитывает использовать локальный LLM endpoint вместо сетевого провайдера по ключу
- **THEN** система не предоставляет такой режим
- **AND** документация направляет его к поддерживаемой конфигурации сетевого провайдера

### Requirement: Конфигурация локального endpoint не считается рабочей

Система SHALL не требовать и не использовать настройки локального endpoint'а для `start`, `iterate` и проверки готовности LLM.

#### Scenario: Пользователь открывает лабораторию
- **WHEN** система проверяет готовность LLM-конфигурации
- **THEN** она учитывает только поддерживаемый сетевой провайдер по ключу
