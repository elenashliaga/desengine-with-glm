# Как установить desengine локально

Эта инструкция поможет установить и запустить локальный сервер desengine на вашем компьютере.

Подходит для Windows, macOS и Linux.

---

## Шаг 1. Проверьте Node.js

Откройте терминал:

- **Windows**: PowerShell, Командная строка или терминал VS Code.
- **macOS**: Terminal или терминал VS Code.
- **Linux**: обычный терминал вашей системы.

Проверьте, установлен ли Node.js:

```bash
node -v
npm -v
```

Если обе команды показывают номера версий, всё в порядке.

Пример:

```bash
v22.11.0
10.9.0
```

Если появляется ошибка вроде `command not found` или `npm is not recognized`, установите Node.js.

Скачайте **LTS-версию** с официального сайта:

```text
https://nodejs.org/
```

После установки закройте терминал и откройте его заново.

---

## Шаг 2. Перейдите в папку проекта

Откройте терминал в корневой папке проекта desengine.

Это папка, где находятся файлы:

```text
package.json
INSTALL.md
README.md
```

Если вы открыли терминал не там, перейдите в папку проекта командой `cd`.

Например:

```bash
cd ~/Documents/Code/desengine
```

---

## Шаг 3. Установите зависимости

В корневой папке проекта выполните:

```bash
npm install
```

Можно использовать короткий вариант:

```bash
npm i
```

Дождитесь завершения установки.

---

## Шаг 4. Создайте файл конфигурации

В корне проекта найдите файл:

```text
desengine.config-example.txt
```

Скопируйте его и назовите копию:

```text
desengine.config.txt
```

Например через терминал:

```bash
cp desengine.config-example.txt desengine.config.txt
```

На Windows в PowerShell можно использовать:

```powershell
Copy-Item desengine.config-example.txt desengine.config.txt
```

---

## Шаг 5. Настройте LLM-провайдера

Откройте файл:

```text
desengine.config.txt
```

Найдите настройки LLM-провайдера.

Укажите, какую нейросеть вы хотите использовать:

```text
LLM_PROVIDER=gemini
```

Допустимые варианты зависят от вашей версии проекта, обычно используются:

```text
openai
deepseek
gemini
```

Затем добавьте API-ключ для выбранного провайдера.

Примеры:

```text
OPENAI_API_KEY=ваш_ключ
DEEPSEEK_API_KEY=ваш_ключ
GEMINI_API_KEY=ваш_ключ
```

Заполнить нужно ключ именно того провайдера, который указан в `LLM_PROVIDER`.

Например, если указано:

```text
LLM_PROVIDER=gemini
```

то должен быть заполнен:

```text
GEMINI_API_KEY=ваш_ключ
```

---

## Шаг 6. Проверьте обязательные параметры

В файле `desengine.config.txt` должны быть указаны эти параметры:

```text
ONBOARDING_REPO_URL=https://github.com/sobakapav/desengine-onboarding.git
ALLOWLIST_SALT=68vBN7EWDTDsMLzoTyOghApJ5zDBI/Mg1ZNGpbrxvIY=
ALLOWLIST_BASE_URL=https://sobakapav.ru/allowlist/
```

Также допустим вариант:

```text
ALLOWLIST_BASE_URL=https://example.com/opvl
```

Если какого-то параметра нет или в нём указано другое значение, исправьте его.

После изменений сохраните файл.

---

## Шаг 7. Проверьте установку

В корневой папке проекта выполните:

```bash
npm run smoke
```

Если всё настроено правильно, проверка должна пройти без критических ошибок.

Если команда сообщает, что локальная установка ещё не готова, прочитайте последние строки вывода. Обычно там написано, какой параметр нужно исправить.

---

## Шаг 8. Запустите локальный сервер

Выполните команду:

```bash
npm run dev
```

Не закрывайте окно терминала, пока работает сервер.

Откройте в браузере:

```text
http://localhost:3000
```

При первом запуске приложение может перенаправить вас на страницу авторизации:

```text
/auth
```

---

## Шаг 9. Авторизуйтесь

Введите email, который вы указывали при покупке задачника.

После успешной авторизации вы получите доступ к лабораторной работе и списку задач.

Обычно список задач доступен по адресу:

```text
http://localhost:3000/tasks
```

Если вы хотите использовать другой email, напишите нам об этом.

---

# Если что-то пошло не так

## Ошибка `npm: command not found`

Это значит, что Node.js или npm не установлены, либо терминал не видит их после установки.

Что сделать:

1. Установите Node.js LTS с официального сайта.
2. Закройте терминал.
3. Откройте терминал заново.
4. Проверьте ещё раз:

```bash
node -v
npm -v
```

---

## Страница `/auth` открывается, но email не принимается

Проверьте файл:

```text
desengine.config.txt
```

Особенно параметры:

```text
ALLOWLIST_SALT
ALLOWLIST_BASE_URL
```

Также убедитесь, что вводите тот email, который был указан при покупке задачника.

---

## Ошибка со словом `TypeScript`, `Build` или `Next.js`

Это похоже на внутреннюю ошибку приложения.

Скопируйте последние строки лога из терминала и отправьте их нам в чат.

Обычно нужны строки после слов:

```text
Error
Build Error
Type error
Failed to compile
```

---

## Сервер запустился, но сайт не открывается

Проверьте, что терминал с командой `npm run dev` всё ещё открыт.

Также проверьте адрес в браузере:

```text
http://localhost:3000
```

Если порт `3000` занят, Next.js может предложить другой порт, например:

```text
http://localhost:3001
```

Откройте тот адрес, который указан в терминале.

---
